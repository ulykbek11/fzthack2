# QoS — предзаказ еды без очередей

QoS — FoodTech-платформа для предзаказа еды в заведениях Алматы. Пользователь сразу попадает в каталог, выбирает ресторан, собирает заказ и указывает удобное время самовывоза.

Бонусы начисляются **не за каждый заказ**. Заведение отмечает менее загруженные временные окна, а QoS предлагает гостю бонус за предзаказ именно на такое время. Так клиент получает выгоду, а кухня распределяет поток заказов и снижает перегрузку в часы пик. В текущем MVP эта механика реализована на уровне интерфейса; серверный расчёт загрузки будет добавлен позже.

## Что есть в проекте

- Каталог из 50 реальных заведений Алматы с поиском, категориями и сортировкой.
- Названия, адреса, координаты, рейтинги и количество отзывов получены через Places API 2ГИС.
- Карточки заведений с бонусными временными окнами, рейтингом и временем приготовления.
- Интерактивная карта Алматы на Leaflet.
- Меню, корзина, выбор времени самовывоза и демонстрационное оформление заказа.
- Бонусы только при выборе отмеченного незагруженного времени.
- Адаптивный интерфейс для desktop, tablet и mobile.
- Ненавязчивый раздел для подключения заведений по адресу `/business`.

## Страницы

- `/` — основной каталог заведений (открывается сразу, без лендинга).
- `/map` — тот же каталог с возможностью переключиться на карту.
- `/business` — форма подключения заведения к QoS.

## Быстрый старт

Требуется Node.js 18.18+ (рекомендуется актуальная LTS-версия).

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run typecheck
npm run build
```

## Данные и ограничения MVP

Данные заведений сохранены в `src/data/mockVenues.ts` как локальный снимок ответа 2ГИС, чтобы каталог стабильно работал без передачи API-ключа в браузер. Меню, изображения, время приготовления, дистанция и бонусные окна пока являются демонстрационными данными.

Расчёт фактической загрузки кухни, автоматическое открытие бонусных слотов, авторизация, оплата и сохранение заказов требуют backend и не входят в текущую итерацию.
