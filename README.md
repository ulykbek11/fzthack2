# ⚡ QoS — Платформа предзаказа еды без очередей

> **«Закажи заранее. Забери без очереди. Получи бонусы.»**

QoS — современная FoodTech-платформа предзаказа еды для кафе, ресторанов и заведений fast food в Алматы. Сервис позволяет гостям заказывать любимые блюда по оригинальной цене заведения без наценок и очередей, а также накапливать кэшбэк-бонусы по номеру телефона.

---

## 🧭 Страницы и возможности

- **Главный лендинг (`/`)**:
  - Презентация ценности для клиентов и заведений.
  - Пошаговый сценарий («Как это работает»).
  - Интерактивный симулятор дашборда для бизнеса.
  - Переключатель тёмной и светлой темы.
- **Интерактивная карта и каталог (`/map`)**:
  - Реальная карта Алматы на базе **Leaflet** и **CartoDB** (Dark Matter для тёмной темы, Voyager для светлой темы).
  - Популярные бренды и заведения Алматы (*Bahandi, Lanzhou, Zheka's Doner, Marrone Rosso, Del Papa, Degirmen* и др.).
  - Поиск по блюдам и кухням, фильтрация (самовывоз, до 15 мин, с бонусами).
  - Модальное окно меню с выбором времени выдачи, корзиной и **вводом номера телефона для начисления бонусов**.
  - Чистый дизайн карточек без лишнего визуального шума.
- **Партнёрский раздел QoS Business (`/business`)**:
  - Условия подключения заведений без покупки дорогого оборудования.
  - Интерактивная форма заявки на интеграцию меню.

## 🛠 Технологический стек

- **Фреймворк:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS 3 + Vanilla CSS (модели Dark / Light)
- **Иконки:** [Lucide React](https://lucide.dev/) (чистые векторные SVG)
- **Картография:** [Leaflet](https://leafletjs.com/) + `@types/leaflet`
- **Шрифты:** Inter (основной текст), Outfit (заголовки)

## 🚀 Быстрый старт для разработчика

Инструкция для быстрого клонирования и запуска проекта на локальной машине:

### 1. Системные требования
- **Node.js:** версия `18.18.0` или выше (рекомендуется `20.x` LTS или `22.x`).
- **Менеджер пакетов:** `npm` (поставляется вместе с Node.js) или `pnpm`/`yarn`.
- **Git**

### 2. Клонирование репозитория
```bash
git clone https://github.com/linee64/fzt-hack.git
cd fzt-hack
```
*(Либо перейдите в папку с проектом, если она уже скачана)*.

### 3. Установка зависимостей
```bash
npm install
```
> Все зависимости (включая Leaflet, Lucide React и Tailwind) зафиксированы в `package.json` и `package-lock.json`. Дополнительных глобальных пакетов ставить не требуется.

### 4. Запуск сервера разработки
```bash
npm run dev
```

После запуска откройте в браузере:
👉 **[http://localhost:3000](http://localhost:3000)**

## 💡 Важные моменты при доработке

1. **Тёмная и светлая тема**:
   - Переключение темы реализовано через класс `.dark` на теге `<html>`.
   - В Tailwind везде используются пары классов: `bg-slate-50 dark:bg-[#090B11]`, `text-slate-900 dark:text-gray-100`, `border-slate-200 dark:border-white/10`.
   - При добавлении новых компонентов обязательно поддерживайте оба режима.

2. **Leaflet & SSR**:
   - Карта Leaflet использует обращение к глобальному объекту `window`, поэтому компонент `RealAlmatyMap` импортируется динамически с отключенным SSR:
     ```tsx
     const RealAlmatyMap = dynamic(() => import("@/components/catalog/RealAlmatyMap"), { ssr: false });
     ```
   - Стили `leaflet/dist/leaflet.css` централизованно подключены в [src/app/layout.tsx](src/app/layout.tsx).

3. **Очистка кэша при сбоях Webpack**:
   - Если при переключении веток или резких изменениях файлов Next.js выдает ошибки кэша в `.next`, просто выполните:
     ```bash
     # Windows PowerShell:
     Remove-Item -Recurse -Force .next
     npm run dev

     # Linux / macOS:
     rm -rf .next
     npm run dev
     ```

4. **Брендинг**:
   - Название продукта строго **QoS**.
   - Не используйте сырые эмодзи в интерфейсе — используйте векторные иконки из `lucide-react`.
