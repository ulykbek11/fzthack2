# QoS — Roadmap

Проект делится на 6 простых фаз.

## Phase 1 — Foundation
Цель: поднять проект и базовую архитектуру.

Сделать:
- Next.js + TypeScript
- Tailwind
- база данных
- Prisma
- базовые layout-компоненты
- роли Customer / Business
- env
- seed с несколькими тестовыми заведениями

Результат: проект запускается, база работает, тестовые данные есть.

Проверка:
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## Phase 2 — Landing + Map
Цель: сделать внешний вид продукта и навигацию пользователя.

Сделать:
- landing: hero, CTA, как работает, выгода пользователю, выгода бизнесу
- map: карта, точки заведений, карточки, фильтры, переход в заведение
- для MVP можно использовать тестовые координаты и тестовые заведения

Результат:
`Landing → Map → Venue`

Проверка:
- responsive
- mobile
- desktop
- typecheck
- lint
- build

## Phase 3 — Venue + Order Flow
Цель: сделать основной customer-flow.

Сделать:
- меню
- категории
- карточки блюд
- корзина
- изменение количества
- итоговая цена
- выбор времени
- оформление заказа
- страница заказа
- pickup code / QR
- статусы заказа

Результат:
`Map → Venue → Menu → Cart → Pickup time → Order`

Проверка: полный заказ проходит вручную без ошибок.

## Phase 4 — Bonuses + Customer Auth
Цель: добавить простую бонусную механику.

Сделать:
- вход по телефону / OTP
- профиль пользователя
- баланс бонусов
- начисление после выдачи
- списание на следующем заказе
- ограничение на списание 20–30%
- история заказов

Результат: пользователь может войти, оформить заказ, получить бонусы и использовать их повторно.

Проверка:
- бонус не начисляется до выдачи
- бонус не начисляется дважды

## Phase 5 — Business Dashboard
Цель: сделать полноценную сторону бизнеса.

Сделать:
- business registration
- login
- создать заведение
- редактировать информацию
- создать позицию меню
- изменить позицию
- удалить / скрыть
- поменять цену
- категории
- статусы заказов: Новые / Готовится / Готов / Выдан / Отменён
- аналитика: заказов сегодня, сумма заказов, популярные позиции, бонусы

Результат: бизнес может самостоятельно подключиться и принимать предзаказы.

## Phase 6 — Polish + Demo
Цель: сделать продукт готовым к защите.

Сделать:
- polished UI
- animations
- skeletons
- loading
- errors
- empty states
- responsive
- mobile UX
- QR/pickup demo
- README
- demo credentials
- seed data
- финальная проверка

Финальный demo:

Клиент:
`Landing → Map → Venue → Order → Pickup`

Бизнес:
`Dashboard → New order → Preparing → Ready → Picked up`

После `Picked up`:
- заказ клиента обновляется
- начисляются бонусы

Final check:
- `npm run typecheck`
- `npm run lint`
- `npm run build`
- основной demo-flow проходит 2 раза подряд без ошибок.
